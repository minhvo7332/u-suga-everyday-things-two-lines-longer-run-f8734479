Entry for the make.fun competition
[Everyday Things, Two Lines, Longer Run](https://make.fun/bounty/u-suga-everyday-things-two-lines-longer-run-f8734479):
a program that writes a two-line explanation of one everyday thing to
`/output/entry.txt`.

Line 1 explains a toaster to a 10-year-old in a single vivid sentence built
on one concrete, surprising analogy — a tiny sun trapped in a metal box.
Line 2 says in one sentence what that analogy maps (the heat that browns
the bread) and what it leaves out (a real sun never switches off, pops up,
or fits on a kitchen counter).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
